# @wasm-forge/text-to-binary

文本与二进制流互转 WebAssembly 模块 (Tool #28)。

## 功能特性
- **双向无损互转**：UTF-8 文本 ↔ 8位二进制流 (如 `Hello` ↔ `01001000 01100101 01101100 01101100 01101111`)。
- **多种分隔符**：空格分隔、连续无空格、逗号分隔、带 `0b` 前缀。
- **位与信息熵统计**：字符数、字节数、0 位数、1 位数与比特密度百分比。
- **纯单一文件**：零 JS 胶水代码，零运行时 Imports，导出标准 WasmForge C-ABI。
