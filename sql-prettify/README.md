# @wasmforge/sql-prettify

SQL 语句排版美化与压缩瘦身工具（SQL Prettifier & Minifier）WebAssembly 纯单一文件实现。

## 特性
- **标准化 SQL 关键词大写与智能缩进**: 基于工业级 `sqlformat` 引擎，支持关键词大写转换、缩进控制、跨查询多语句格式化。
- **快速注释剔除与空格压缩**: 极速过滤 `--` 单行注释与 `/* ... */` 多行块注释，安全保留单双引号内部字符串原样。
- **纯单一文件**: 零 JS 胶水代码，零外部环境依赖，0 imports。
- **双运行时支持**: 浏览器客户端与 Node.js / Hono 服务端无缝复用。
