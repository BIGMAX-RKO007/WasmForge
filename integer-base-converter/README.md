# @wasm-forge/integer-base-converter

任意进制整数转换 WebAssembly 模块 (Tool #26)。

## 功能特性
- **支持 2 ~ 36 任意进制互转**：二进制、八进制、十进制、十六进制、Base36。
- **智能前缀嗅探**：支持自动识别 `0b`（二进制）、`0o`（八进制）、`0x`（十六进制）。
- **位与字节分析**：计算最小有效位宽（Bit Length）、字节数、大端序/小端序十六进制字节序列。
- **补码计算**：支持负数及 8/16/32/64 位补码展示。
- **纯单一文件**：零 JS 胶水，零运行时 Imports，导出标准 WasmForge C-ABI。
